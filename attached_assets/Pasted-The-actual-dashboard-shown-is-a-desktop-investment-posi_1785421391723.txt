Spacing philosophy

This dashboard uses two different spacing modes.

The summary area is spacious, while the positions table is intentionally dense.

A good spacing system would be:

Page horizontal margin:       20px
Major panel gap:              12px
Panel heading padding:        14–20px
Summary vertical padding:     22–28px
Metric horizontal gap:        20–30px
Table header padding:          6–10px
Table cell horizontal pad:     7–10px
Table cell vertical pad:       5–7px

This contrast is important.

Don't give every table cell 16–24 px padding or it will stop looking like this type of brokerage interface.

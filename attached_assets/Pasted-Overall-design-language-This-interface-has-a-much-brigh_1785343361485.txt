Overall design language

This interface has a much brighter, cleaner retail-banking aesthetic than the previous screenshot.

The core visual formula is:

white canvas + Citi-style royal blue + pale blue-grey navigation + charcoal typography + thin grey borders + moderately rounded cards + subtle shadows.

The page is approximately 1,440 px wide in the browser viewport. Content nearly fills the viewport horizontally, with approximately 30–65 px outer margins.

There is very little dark colouring. Blue is the dominant interactive colour.

Typography

The screenshot uses a clean humanist sans-serif family. A reasonable approximation is:

font-family:
  Arial,
  Helvetica,
  "Helvetica Neue",
  sans-serif;

If you want something slightly closer in character, use:

font-family:
  "Helvetica Neue",
  Arial,
  sans-serif;

The important characteristic is not geometric SaaS typography. Avoid fonts such as Poppins or Montserrat.

Body copy should feel conventional and highly readable.

Spacing system

A developer could build the interface around an 8 px spacing system:

--space-1: 4px;
--space-2: 8px;
--space-3: 12px;
--space-4: 16px;
--space-5: 24px;
--space-6: 32px;
--space-7: 48px;
--space-8: 64px;

Forms generally use 8–16 px internal gaps.

Navigation uses 30–45 px horizontal separation.

Major page regions use 40–70 px spacing.

Border-radius hierarchy

This screenshot uses radius deliberately:

Navigation tabs:        0 px
Mega menu:              ~0–6 px
Text inputs:            ~8 px
Primary buttons:        ~7 px
Login card:             ~17 px
Shortcut container:     ~17 px
Product cards:          ~8 px
Circular icons:         50%

So don't apply one universal radius everywhere.

Shadow hierarchy

Keep shadows subtle.

The navigation:

box-shadow: 0 2px 6px rgba(0,0,0,.08);

Dropdown:

box-shadow: 0 4px 10px rgba(0,0,0,.16);

Login card:

box-shadow: 0 3px 14px rgba(0,0,0,.18);

Normal content cards should mostly rely on their 1 px border rather than shadows.
